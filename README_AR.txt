SocialNet — النسخة المحدثة

المزايا: تسجيل الدخول، جلسات PostgreSQL، المنشورات، رفع صور المنشورات إلى Cloudinary، معاينة قبل النشر، صور الحساب، التعليقات مع الصور، الملفات الشخصية، البحث، نظام الأصدقاء، الرسائل مع صور المرسلين، تصميم الهاتف والكمبيوتر، RTL، والوضع الداكن.

متغيرات Render المطلوبة:
DATABASE_URL
SITE_PASSWORD
COOKIE_SECRET (اختياري حسب إعداد الخادم الحالي)
CLOUDINARY_CLOUD_NAME
CLOUDINARY_API_KEY
CLOUDINARY_API_SECRET

في Render استخدم Start Command: npm start
لا تضع أسرار Cloudinary داخل GitHub.

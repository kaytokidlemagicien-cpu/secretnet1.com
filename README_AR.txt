SocialNet — النسخة الحقيقية متعددة الأجهزة

هذه النسخة تستخدم:
- Node.js + Express للخادم.
- PostgreSQL لتخزين المستخدمين والمنشورات والتعليقات والإعجابات والرسائل.
- كلمة مرور الموقع: Boss2026 (يُفضّل تغييرها في متغير البيئة SITE_PASSWORD).
- Cookie موقعة لحفظ جلسة المستخدم.
- Helmet وRate Limiting وحماية Origin الأساسية.

التشغيل على الكمبيوتر:
1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   npm install
4. أنشئ قاعدة PostgreSQL وأنشئ الجداول بتنفيذ محتوى schema.sql.
5. انسخ .env.example إلى .env وضع:
   DATABASE_URL=...
   SITE_PASSWORD=Boss2026
   COOKIE_SECRET=ضع-هنا-سرًا-طويلًا-عشوائيًا
6. شغّل:
   npm start
7. افتح:
   http://localhost:3000

النشر على الإنترنت:
- استخدم استضافة تدعم Node.js مثل Render أو Railway أو منصة مشابهة.
- استخدم PostgreSQL مُستضافًا.
- أضف متغيرات البيئة DATABASE_URL وSITE_PASSWORD وCOOKIE_SECRET.
- أمر البناء: npm install
- أمر التشغيل: npm start
- بعد النشر سيعطيك مزود الاستضافة رابط HTTPS يمكن مشاركته مع الأصدقاء.

مهم:
- كلمة المرور ليست موجودة في JavaScript الخاص بالمتصفح؛ التحقق منها يتم على الخادم.
- لا تشارك DATABASE_URL أو COOKIE_SECRET.
- النسخة الحالية تحفظ الصور كرابط صورة، وليست رفع ملفات. يمكن إضافة رفع الصور لاحقًا عبر Storage.
- الرسائل تُحفظ في PostgreSQL، لذلك يراها المستخدمون من أجهزة مختلفة.
- هذه النسخة لا تحتوي بعد على إشعارات فورية WebSocket؛ يمكن إضافتها لاحقًا.

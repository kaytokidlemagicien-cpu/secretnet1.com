SocialNet Pro 2.0 — الأصدقاء والرسائل تعمل فعليًا
================================================

هذه النسخة مبنية على SocialNet Pro مع صورة الملف الشخصي، وتمت إضافة Backend كامل داخل server.js.

المزايا الجديدة:
- نظام أصدقاء حقيقي في PostgreSQL.
- إرسال طلب صداقة.
- قبول/رفض الطلبات.
- حذف صديق.
- مراسلة أي مستخدم.
- حفظ الرسائل في PostgreSQL.
- تحديث المحادثة تلقائيًا كل 2.5 ثانية.
- صور داخل الرسائل ما زالت تعمل عبر Base64 للصور الصغيرة.
- صورة الملف الشخصي تُحفظ الآن عبر API في قاعدة البيانات، بدل localStorage فقط.
- الحفاظ على الواجهة الحالية RTL والمتجاوبة والوضع الليلي.

التشغيل على Render:
1. ارفع محتويات هذا المجلد إلى GitHub.
2. تأكد أن Build Command هو: npm install
3. Start Command هو: npm start
4. أضف Environment Variables:
   DATABASE_URL=رابط PostgreSQL الخاص بك
   SITE_PASSWORD=Boss2026
   NODE_ENV=production
5. لا ترفع ملف .env إلى GitHub.

مهم:
- الصور بصيغة Base64 داخل PostgreSQL مناسبة للتجربة والصور الصغيرة، لكن للإنتاج الأفضل استعمال Cloudinary أو S3 وتخزين الرابط فقط.
- لا تغيّر DATABASE_URL إلى قيمة موجودة في GitHub أو تشارك كلمة مرور قاعدة البيانات.
